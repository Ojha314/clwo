# 💰 Expense Tracker

A beautiful mobile Expense Tracker app built with **Flutter**.

## 📸 Screenshots

> Add screenshots here after running the project

## ✨ Features

- 💸 Add Income & Expense transactions
- 🏷️ Multiple Categories (Food, Travel, Shopping, Bills, etc.)
- 📊 Pie Chart — Expense by Category
- 💾 Local Storage — Data saved permanently
- 🗑️ Swipe to Delete transaction
- 📅 Date picker for transactions
- 💚 Color coded — Green for Income, Red for Expense
- 📱 Beautiful Mobile UI

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| Flutter | Mobile Framework |
| Dart | Programming Language |
| SharedPreferences | Local Storage |
| FL Chart | Pie Chart |
| UUID | Unique IDs |
| Intl | Date Formatting |

## ⚙️ Installation

### 1. Clone the repository
```bash
git clone https://github.com/Ojha314/expense-tracker.git
cd expense-tracker
```

### 2. Install dependencies
```bash
flutter pub get
```

### 3. Run the app
```bash
flutter run
```
